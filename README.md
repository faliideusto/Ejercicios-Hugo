# Hugo Monroux · Training Lab

Web de entrenamiento personal:

- **Simulador biomecánico** de 14 ejercicios: qué músculo trabaja y por qué.
- **Rutina y volumen**: rutinas por días con más de 240 ejercicios y series semanales por músculo.
- **Seguimiento**: registro de pesos y repeticiones, progreso y 1RM estimado.
- **Calorías y macros**: mantenimiento, déficit y volumen con proteína, carbohidratos y grasas.

Es una web estática (HTML + JS, sin dependencias). Basta con abrir `index.html` o publicarla en GitHub Pages.
Los datos se guardan en el navegador (`localStorage`); desde Seguimiento se puede exportar e importar una copia.
